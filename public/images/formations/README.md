# Photos des pages formation — à remplacer

Chaque page de formation TAXI a son propre set de **3 photos** (placeholders actuellement). Adil doit fournir les 3 photos définitives pour chaque page.

| Dossier | Page concernée |
|---|---|
| `taxi-initiale/` | `/formation-taxi/formation-initiale` |
| `taxi-continue/` | `/formation-taxi/formation-continue` |
| `taxi-mobilite/` | `/formation-taxi/formation-mobilite` |
| `taxi-passerelle/` | `/formation-taxi/formation-passerelle` |

Pour chaque dossier, déposer 3 fichiers nommés exactement :
- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`

Résolution minimale : 1600 × 900 px, format JPG, ≤ 400 Ko après compression.

Les 3 photos sont recyclées sur les 6 emplacements visuels du template (mosaïque, mini-galerie sidebar, photo breaks inline).
